<objective>
Build `SeriesNormalization` — the presentation-agnostic primitive that supplies the FIXED honest domain per `ScaleKind` and a readout that ALWAYS reports the REAL value + unit (never the normalized [0,1] number). This is what Phase 15 needs to make the deferred lanes-vs-labeled-normalization call WITHOUT silently misleading the user: the domain per scale-kind is FIXED (0...10, 1...5, 1...4, 0...24, 0...240), never per-visible-window min/max (Pitfall 4 — per-window normalization is a Phase-15 presentation decision, explicitly out of scope here), so a series' shape stays stable across window switches.

Purpose: Lock the honest-domain + real-unit-readout invariants in unit tests. `normalize` maps a real value onto the unit interval for shape-only overlay and round-trips exactly via `denormalize`; the readout NEVER reports the normalized number — only the real value + unit — so even when Phase 15 normalizes for visual overlay, every value the user READS is honest (no silent normalization).

Output: `SeriesNormalization.swift` (`domain(for:)` + `normalize` + `denormalize` + `readout`) + `SeriesNormalizationTests.swift` (per-kind domain, round-trip, real-unit readout, presence-nil-domain).
</objective>
