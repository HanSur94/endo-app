<objective>
Build `ExploreSeriesExtraction` — THE structural honesty move of the phase: two kind-gated entry points returning two DIFFERENT types. `quantitativePoints(...) -> [InsightPoint]` for quantitative series (nil field → no point/gap; logged 0 → a real point at 0) and `occurrenceDays(...) -> [Date]` for presence/event series. Because the presence path returns `[Date]` with NO `value` field, "coerce a tag to a 0/1 value" is not expressible in the type system (RESEARCH Pattern 1 / Pitfall 1) — the success criterion is enforced by construction, not by a runtime check.

Purpose: Lock the absence-≠-0 and presence-unrepresentable-as-0/1 honesty invariants in unit tests before any Explore pixel exists (the ChartScrubSelectionTests playbook). Emit the existing `InsightPoint` so the shipped app-side `ChartSeriesGrouping` (gap-breaking runs) and `ChartScrubSelection` (scrub resolver) are reused UNCHANGED downstream (LOCKED reuse decision). Gate both bleeding-derived series on `suppressed` so a suppressed user's bleeding cannot leak (Pattern 3 / Pitfall 4).

Output: `ExploreSeriesExtraction.swift` (two pure static funcs) + `ExploreSeriesExtractionTests.swift` (the five honesty fixtures: gap, logged-0, presence-not-coerced, presence-absent, suppression no-leak).
</objective>
