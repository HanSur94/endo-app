<objective>
Ship the payoff slice: a user can reach a report builder from Settings, pick a date range, tap Generate
to produce the on-device PDF, see it in a PDFKit preview, and share it through the system share sheet
with NO automatic upload.

This wires the Plan-01 model + Plan-02 renderer into the live consented shell: a Settings "Export report"
row -> ReportBuilderView (preset + custom DatePickers + Generate, disabled until valid) -> generate the
temp-file PDF on-device -> ReportPreviewView (PDFView + ShareLink) -> delete the temp file on dismiss.
It also locks the no-upload invariant (RPRT-03) as a grep-assertable source-scan test and proves the
flow end-to-end with XCUITest.

Purpose: deliver RPRT-01 (generate on-device for a chosen range) + RPRT-03 (share via the system sheet,
no silent upload) as a real user-facing capability, with the V8 temp-file-cleanup mitigation.
Output: ReportBuilderView, ReportPreviewView, PDFKitView, the Settings entry, ReportNoNetworkTests,
ReportFlowUITests + the -uitest-seed-report fixture wiring.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| temp PDF file | a throwaway file of GDPR Art.9 special-category health data living in temporaryDirectory until dismiss |
| share action | the only egress of the PDF off-device — must be explicit user action, never automatic |
| report module imports | the no-network surface that keeps the no-silent-upload guarantee true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-09 | Information Disclosure | temp PDF on disk after dismiss | mitigate | Write to FileManager.temporaryDirectory (NOT Documents/iCloud); delete on preview dismiss + before each regeneration (Pitfall 5 / V8/V12) |
| T-10-10 | Information Disclosure / Repudiation | silent/auto upload of the PDF | mitigate | NO network path in the report module — ReportNoNetworkTests grep-assert; share is an explicit ShareLink tap bound to a local file URL only (RPRT-03/D-09) |
| T-10-11 | Access Control | report reachable pre-consent | mitigate | The entry is in SettingsView, which lives under AppGate's .consented branch (V4); Repository reads are consent-gated. No new gate needed |
| T-10-12 | Denial of Service | unbounded free-text echoed into the PDF | accept | Notes are already length-bounded at the Repository seam; CoreText wraps/truncates — no new surface |
| T-10-13 | Tampering | UI test fixture leaking to a real store | mitigate | -uitest-seed-report is GATED behind -uitest-reset (in-memory store), so it can never write a real store (T-08-06) |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | Phase 10 installs ZERO external packages (first-party + in-repo only) |
</threat_model>
