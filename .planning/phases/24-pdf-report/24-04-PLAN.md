<objective>
Deliver the no-silent-upload share (AREL-02): write the rendered PDF to an app-private `cacheDir/reports/`, vend it as a scoped `content://` URI through a `FileProvider`, and hand it to the OS `ACTION_SEND` chooser so the USER picks the target — the app never touches the network and never auto-uploads. Clean the cache PDF after the chooser returns. Enforce it structurally with a no-network source scan over `com.endoapp.app.report` and a manifest test asserting the `<provider>` is present and NO `INTERNET` permission exists.

Purpose: This is the T-24-01 mitigation — the OS chooser is the ONLY egress, per-share scoped and revocable, backed by grep-provable no-network posture.

Output: the FileProvider manifest entry + `file_paths.xml`, `ReportShareHost`, and the no-network / manifest / share-host tests.
</objective>
