<objective>
Render the pure `ReportModel` (Plan 02) into a clinician-credible, multi-page, on-device VECTOR PDF via first-party `android.graphics.pdf.PdfDocument` — and make "the text is selectable-vector, not a raster snapshot" PROVABLE on the JVM lane. Because Android has no first-party PDF text extractor (`PdfRenderer` is bitmap-only), the proof pivots to a draw-instruction seam: the renderer draws through a `ReportCanvas` interface, and a pure-Kotlin `RecordingReportCanvas` spy asserts the renderer called `drawText`/`drawWrapped` for the expected copy and NEVER a raster path for text. The embedded trend chart reuses the Phase-22 geometry via a `Canvas → DrawScope` bridge, drawn single-ink black with the SAME honest break geometry as on-screen.

Purpose: Selectable vector text + exact copy + correct pagination + honesty-identical chart are the AREL-01 render invariants — all made testable without an emulator.

Output: `ReportCanvas` seam, `ReportPdfRenderer` (two-pass), `ReportChartAdapter`, the recording-seam JVM tests, and the instrumented `%PDF`-bytes/page-count smoke.
</objective>
