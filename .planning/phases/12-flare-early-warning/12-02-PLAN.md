## FlareEngine scoring heuristic (Claude's discretion per CONTEXT — the conservative default from RESEARCH Pattern 1; LOCKED structure)

`enum FlareEngine { static func flareWarning(from: [DaySnapshot], asOf today: Date, calendar: Calendar = .current) -> [Insight] }`

Order of operations (the conservative shape — DO NOT deviate from the rising-spine-REQUIRED rule):
1. **Suppressed short-circuit FIRST** — `guard !snapshots.contains(where: { $0.suppressed }) else { return [] }` (no phantom warning; mirror RecommendationsEngine line 59).
2. **Signal A — rising-severity spine (REQUIRED).** Compose `TrendsEngine` helpers (do NOT re-derive): bucket the dominant logged symptom over `.last30`, compare recent-vs-prior mean severity via `TrendsEngine.direction`. Define `RisingSignal { symptom; loggedDays }` where `loggedDays` = days-with-a-logged-severity-for-that-symptom in `.last30`'s recent bucket. Return nil if NO symptom is rising (`direction != .up`). The dominant symptom = the one with the most logged severity days in the recent bucket (tie → lowest `rawValue`, deterministic). If nil → `return []` (silence is honest — NOT an insufficiency notice).
3. **Signal B — currently-active aggravating triggers.** Reuse `CorrelationEngine.scoredCandidates(...)`; count the `.aggravating` survivors whose factor the user logged on at least one recent day (the recent `.last30` bucket). Count only (`activeTriggerCount`).
4. **Signal C — cycle-phase proximity.** Reuse `CyclePhaseMapper.phaseWindows(...)` (inherits []-on-suppressed/irregular/<2-cycle). `nearHigherPhase` = today falls in a phase window AND that phase has the most logged dominant-symptom days historically (a "historically higher-symptom phase"). Boolean. If no windows → false.
5. **Evidence floor (D-05 — honest "not enough data yet" OR omit, never a fabricated warning).** `let evidence = rising.loggedDays`. If `evidence < HonestyGate.minSample(for: .flare)` (== 21): per A3, emit a SINGLE `isInsufficiencyNotice` "not enough data yet" `.flare` card ONLY when there is a real recent rising signal but sub-threshold evidence (which is exactly this branch); else (no rising signal, handled in step 2) stay silent. Return `[insufficiencyNotice(window: .allTime)]`.
6. **Bounded combine (D-03 — a likelihood, never a number/binary).** Start at `.low` (the rising spine exists). `+1 notch` if `activeTriggerCount >= 1`; `+1 notch` if `nearHigherPhase`. CAP at `.medium` (NEVER `.high` — mirror CyclePhaseMapper's .medium cap). `guard confidence >= .low` (bias to withhold). Emit exactly ONE `.flare` Insight.

`makeFlareInsight`: `Insight.derived(kind: .flare, window: .allTime, signalKey: "flare.warning", headline: FlareCopyText.headline, detail: FlareCopyText.detail (+ optional contributing note), confidence: <bounded>, points: [], sampleSize: evidence)`. The contributing note is derived from the TYPED signals (activeTriggerCount>0, nearHigherPhase) — NEVER parsed from copy — and is the curated `FlareCopyText.contributing` appended only when at least one secondary signal fired.

`insufficiencyNotice`: `Insight.derived(kind: .flare, window: .allTime, signalKey: "flare.warning", headline: FlareCopyText.insufficientTitle, detail: FlareCopyText.insufficientSubtitle, confidence: .none, points: [], sampleSize: <evidence>, isInsufficiencyNotice: true)`. NOTE: the insufficiency card shares the SAME signalKey "flare.warning" (one flare signal); the typed `isInsufficiencyNotice` marker (NOT a signalKey suffix — WR-01) carries it past the gate floor.
