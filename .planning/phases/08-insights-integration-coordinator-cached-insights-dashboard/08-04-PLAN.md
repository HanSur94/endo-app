| Boundary | Description |
|----------|-------------|
| consent gate → dashboard | The Insights UI (health-derived) must be constructed ONLY in the `.consented` branch. |
| user dismiss → store → CloudKit | A dismiss writes a `DismissedInsight` that syncs to the private DB and must keep the card gone. |

| T-08-13 | Information disclosure (honesty surface) | suppressed → phantom cycle phase | mitigate | A section with zero gated insights is OMITTED; the engine emits zero `.cyclePhase` for suppressed/irregular users, so the cycle-phase section is provably ABSENT (the E2E asserts non-existence) — no phantom phase, no "cycle hidden" placeholder (D-07). |
| T-08-14 | Repudiation | a dismissed card reappears | mitigate | Dismiss persists a `DismissedInsight` (Phase 6, syncs via Phase 4) AND triggers `dataChanged()` → recompute with the dismissed signalKey excluded (D-09/D-10); the E2E `dismiss_removesCard_andStaysGone` asserts it does not return across a relaunch. |
