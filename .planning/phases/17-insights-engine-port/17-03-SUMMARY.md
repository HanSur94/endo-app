## Accomplishments

- **`SpecialFunctions.kt`** — the two C-libm functions Kotlin/JVM does not expose, hand-rolled and pinned:
  - `lgamma(x)` via **Lanczos g=7** (canonical 9-coefficient set) with Euler reflection for `x<0.5`. Anchor holds: `lgamma(5.0) == ln(24) == 3.17805383`.
  - `erf(x)` / `erfc(x)` via the **Numerical-Recipes 28-term Chebyshev `erfc` fit** (~1e-15) — deliberately not the low-order Abramowitz-Stegun rational that would drift Mann-Whitney p's.
  - `normalCDF(x) = 0.5·(1 + erf(x/√2))` — verbatim mirror of Swift.
  - `Double.roundedAwayFromZero()` = `if (this < 0) -floor(-this + 0.5) else floor(this + 0.5)` — Swift `.rounded()` half-away-from-zero parity.
  - **kotlin.math-only** (BoundaryLintTests stays green).
- **`CorrelationStats.kt`** — verbatim 1:1 port of `CorrelationStats.swift` (the Swift suite is the oracle; the math was NOT "improved"):
  - Cliff's δ, `meanDifference`, `riskDifference`/`riskRatio` (with the `guard reference > 0` → null), Fisher exact (lgamma-backed `lnChoose`→`hypergeometricProbability`→`exp`, **load-bearing `1 + 1e-7` epsilon** reproduced), tie-corrected Mann-Whitney U (**no ±0.5 continuity term**), Benjamini-Hochberg (stable value-then-index sort), and confidence bands with the exact constants (`highSampleFloor=30`, `mediumSampleFloor=20`).
  - `List<Double>.sorted()` + `compareBy({ pValues[it] }, { it })` — never `DoubleArray.sort()` (unstable + total-orders NaN differently).
- **`stats-goldens.json`** — libm `lgamma`/`erf`/`normalCDF` golden table generated from a **throwaway standalone Swift snippet** (`scratchpad/gen_goldens.swift`, `import Foundation` only), covering the CorrelationStatsTests domain. Committed with a header documenting the generation command, the Swift toolchain (Apple Swift 6.3.3), and the tolerance (relative **1e-9**, absolute floor 1e-12). **No file was added to or modified in `EndoInsights/` or `Sources/`** (verified: `git status` on the iOS tree is empty).
- **`SpecialFunctionsGoldenTests.kt`** — the AENG-06 / T-17-07 gate: reads the committed goldens and asserts the hand-rolled functions match Swift/libm within the documented tolerance (relative 1e-9, absolute floor near zero). 3 tests (lgamma, erf, normalCDF).
- **`CorrelationStatsTests.kt`** — the 26-case oracle ported 1:1. Exact / 1e-12 assertions kept for the pure integer/double helpers (Cliff, meanDiff, RD/RR, BH index sets); the Swift suite's own tolerances kept for the lgamma/erf-dependent p-values (Fisher 1e-3, Mann-Whitney/normalCDF 1e-6, symmetry 1e-9).
- **`NumericDivergenceTests.kt`** (NEW — AENG-06) — the stats/boundary half of the pack: rounding half-away-from-zero pinned against banker's/half-up (divergence confined to ±.5 ties); Mann-Whitney tied ranks (degenerate-σ `[3,3,3]v[3,3,3]`→p=1.0 and mixed-tie `[5,5,4]v[4,4,4]`→**0.11384629800665813**, a Swift/libm golden); NaN/±Infinity unrepresentable at the DaySnapshot boundary and `-0.0`→`+0.0` canonicalization with structural-equality parity. The DST/non-UTC day-boundary half is **stubbed with a clearly-marked section header for 17-08** (no placeholder @Test — the header is the contract).

## How the goldens were generated

- Throwaway snippet `scratchpad/gen_goldens.swift` (`import Foundation` only) prints libm `lgamma`/`erf`/`normalCDF` at `%.17g` for a domain covering the test call sites (lgamma 0.5…171; erf/normalCDF spanning the Mann-Whitney/normalCDF z-values incl. z=2.6457513110645907).
- Run with `swift gen_goldens.swift`; stdout captured, validated as JSON, and committed as `stats-goldens.json` with a documented header.
- The Mann-Whitney tied-rank golden (`0.11384629800665813`) was computed by a second throwaway snippet (`scratchpad/mw.swift`) running the identical tie-corrected formula through libm.
- **Environment note:** `swift` WAS available (Apple Swift 6.3.3, macOS arm64) — the environment-gated fallback described in the plan/constraints was NOT needed; all goldens are real Swift/libm output, none fabricated.
