<objective>
Deliver the day-log editor vertical slice: replace `WalkingSkeletonView` with a real `HomeView` (reverse-chronological day history + a prominent "Log today" entry + the existing Settings route), and build the `DayLogEditorView` where a user fast-selects endo symptoms, sets 0–10 severity per symptom (reusable `SeverityControl` with mild/moderate/severe presets), records a per-day bleeding flow (+optional clots), and writes a length-bounded free-text note — all persisted through an extended `Repository` and SwiftData `@Query`.

SYMP-01, SYMP-03, and CYCL-01 go GREEN end-to-end (symptom + note + bleeding logging). The body map (SYMP-02), edit/delete (SYMP-04), and the cycle summary (CYCL-02/03/04) land in Plan 04.
