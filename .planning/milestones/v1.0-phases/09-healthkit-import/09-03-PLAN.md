<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User to HealthKit authorization | The system sheet is OS-owned; the in-app rationale precedes it (D-06) but cannot read/set the grant. |
| HealthKit (real HKHealthStore) to app | The real reader isolates the non-`Sendable` store; only Sendable values escape (Pitfall 2). |
| App consent gate to health UI | Health UI is constructed only in the `.consented` AppGate branch (T-09-13). |
| Fixture seam to production | The `-uitest-health-*` fixtures must never touch a real store or HKHealthStore. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-12 | Information Disclosure | Read-status probing to infer the user's health state | mitigate | Honor Apple's hidden read status: never branch UI on `authorizationStatus(for:)` for reads; status decides only the entry affordance (rationale vs deep-link-to-Settings) — Pitfall 1. |
| T-09-13 | Elevation of Privilege / Access Control | Health UI reachable before app consent | mitigate | All connect/rationale/badge UI is constructed only inside the `.consented` `ConsentedShell` (AppGate); the import service is consent-guarded (09-02 T-09-08). |
| T-09-14 | Spoofing / Tampering | Write access requested when only read is intended | mitigate | `requestAuthorization(toShare: [], read:)` and `NSHealthShareUsageDescription` ONLY — no write/share entitlement, no `NSHealthUpdateUsageDescription`; verified by the Info.plist/entitlement grep gate. |
| T-09-15 | Information Disclosure | Health copy leaking causal/medical claims or gendered tokens | mitigate | `HealthConnectCopy` routed through the ClaimsPolicy audit (forbidden verbs + gendered tokens); `HealthConnectCopyAuditTests` is the choke-point. |
| T-09-06 | Tampering | Fixture seam leaking into production | mitigate | The `-uitest-health-*` fixture reader is selected only with the launch args AND paired with the in-memory `-uitest-reset` store (T-08-06 pattern); unreachable on a normal launch. |
| T-09-SC | Tampering | npm/pip/cargo/SPM installs | accept | Zero new third-party packages; HealthKit/HealthKitUI are first-party Apple system frameworks (RESEARCH Package Legitimacy Audit). |
</threat_model>
