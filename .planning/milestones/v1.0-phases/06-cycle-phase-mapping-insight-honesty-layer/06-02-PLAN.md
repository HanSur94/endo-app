<objective>
Build the cross-cutting insight-honesty layer (INST-04): a single shared `HonestyGate` choke-point (per-kind min-sample withholding, confidence floor, dismissal-exclusion, non-causal forbidden-term scan), wrap trends + cycle-phase behind the ONE public `InsightsEngine.insights(from:asOf:dismissed:)`, and demote `TrendsEngine` to package-internal — all per D-05/D-06/D-07/D-08/D-11/D-13/D-16.

Purpose: The honesty gate is the product's ethical core and the mandatory choke-point for every present and future insight kind (Phases 7/11/12 route through it — lock the API now, D-16). Under-sampled/low-confidence findings are WITHHELD, never caveated-and-shown; non-causal language is enforced by a test, not trusted. This is what separates the app from a noise-generating tracker.

Output: `ForbiddenTerms.swift`; `HonestyGate.swift`; `InsightsEngine.swift` (the single public API); `TrendsEngine` internal; `HonestyGateTests`; `InsightsEngineTests`.
</objective>
