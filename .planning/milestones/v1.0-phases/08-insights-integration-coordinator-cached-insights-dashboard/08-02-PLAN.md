<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main actor → background `Task.detached` | `Sendable` value snapshots cross into the off-main pure-engine compute; results cross back. |
| coordinator → Repository | All store reads/writes go through the consent-gated Repository seams (08-01). |
| launch args → in-memory store | `-uitest-seed-insights` injects a fixture; must never touch a real on-disk/CloudKit store. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Information disclosure | coordinator off-main compute / logging | mitigate | The coordinator MUST NOT log health data: no `print`/`os_log` of snapshots, dismissed keys, or insight copy. Only `Sendable` values cross to `Task.detached`; the engine is Foundation-only and pure (no logging by contract). Reviewed: the coordinator emits no diagnostics carrying health-derived content. |
| T-08-06 | Tampering / data integrity | `-uitest-seed-insights` fixture | mitigate | The seed arg inserts ONLY into the in-memory store and is paired with `-uitest-reset` (in-memory configuration) so it can never write to the user's real local/CloudKit store. It is a test-only seam (same posture as `-uitest-reset`). |
| T-08-07 | Repudiation | stale cache surfaces a dismissed insight | mitigate | The fingerprint includes the dismissed-set canonical (Task 1) → a dismiss flips the fingerprint → recompute (cache miss) → the engine excludes the dismissed signalKey (D-10); `replaceCachedInsights` clears stale rows. The user's "this isn't right" is honored. |
| T-08-08 | Access control | coordinator reads before consent | mitigate | The coordinator only reaches the store via the consent-gated Repository seams (08-01 `assertConsented()`); the dashboard that drives it is built only in the `.consented` branch (08-04 / AppGate invariant). |
| T-08-SC | Tampering | npm/pip/cargo/SPM installs | accept | Zero new third-party packages (Swift Concurrency + SwiftData are first-party). No install task; no legitimacy gate needed. |
</threat_model>
