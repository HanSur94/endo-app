<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → SwiftData store → CloudKit private DB | `CachedInsight` rows persist locally and sync to the user's PRIVATE iCloud DB (Phase 4). The serialized blob crosses this boundary. |
| consent gate → Repository | No health-derived read/write may occur before explicit consent (ONBD-01). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information disclosure | `CachedInsight.payload` blob | mitigate | Encode ONLY the engine's gated `Insight` (non-causal gate-audited headline/detail + category `signalKey` + numeric points) — never a `DaySnapshot` and never raw note prose. The encoder takes `Insight`, not the snapshot. GDPR Art.9-adjacent: same category-level data the engine already emits, no MORE. Verified by the round-trip test asserting the stored value is an `Insight`. |
| T-08-02 | Elevation of privilege / access control | `loadCachedInsights` / `replaceCachedInsights` | mitigate | Both call `assertConsented()` first (V4 / ASVS L1) — mirrors every sibling Repository read; a cache read before consent is impossible. |
| T-08-03 | Tampering / data integrity | V4→V5 migration under CloudKit | mitigate | `.lightweight` stage only — `.custom` hooks silently never fire under CloudKit (Phase 4 live). Purely additive (one new model) ⇒ lightweight is correct AND sufficient; recompute rebuilds the cache so a skipped migration cannot corrupt derived data. |
| T-08-04 | Denial of service (crash) | corrupt/`nil` `payload` blob | accept→mitigate | `loadCachedInsights` `compactMap`-skips an undecodable blob rather than crashing (V5 input validation); a corrupt cache degrades to "recompute", never a fatal read. |
| T-08-SC | Tampering | npm/pip/cargo/SPM installs | accept | Zero new third-party packages this phase (Swift Charts + Codable + SwiftData are all first-party Apple frameworks; RESEARCH "no Package Legitimacy Audit required"). No install task, no legitimacy gate needed. |
</threat_model>
