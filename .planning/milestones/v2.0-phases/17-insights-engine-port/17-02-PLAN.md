## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored raw String → enum decode | A corrupt/unknown raw value (from a future Room row or export) must degrade, never crash |
| Kotlin enum/copy → Swift source of truth | Silent divergence in raw values would break signalKey/dismissal parity across platforms |
| caller Double → DaySnapshot | NaN/±0.0 entering the read model would corrupt downstream stats and equality |
