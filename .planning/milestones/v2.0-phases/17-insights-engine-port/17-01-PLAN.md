|----------|-------------|
| dependency catalog → build graph | A supply-chain coordinate entering libs.versions.toml would pull third-party code into the privacy-first module |
| :insights source → platform | Any android./androidx. import would couple the pure engine to a platform runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01 | Tampering | libs.versions.toml (supply chain) | high | mitigate | VersionCatalogAuditTests fails on any analytics/auth/backend/networking coordinate — the standing zero-dependency guard (ASVS V14) |
| T-17-02 | Tampering | :insights/src/main imports | medium | mitigate | BoundaryLintTests source scan fails on any android./androidx. import — keeps the engine portable/pure |
| T-17-SC | Tampering | Maven coordinate provenance | low | accept | All coordinates are first-party JetBrains/JUnit (research Package Legitimacy Audit); no npm/pip/cargo install, so no [ASSUMED]/[SUS] human checkpoint applies — the catalog-audit test is the standing control |
