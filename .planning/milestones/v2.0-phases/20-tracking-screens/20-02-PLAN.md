## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Check-In draft → EndoRepository | A partially-filled or empty check-in must persist an honest marker, never invented rows. |
| Reminder deep link → check-in | An external entry must not surface health UI before consent. |
