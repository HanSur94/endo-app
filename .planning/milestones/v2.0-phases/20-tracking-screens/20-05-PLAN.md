## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reminder notification → OS notification surface | A semi-public lock screen must never reveal health/flare content. |
| Notification deep link → app | An external tap must land on the consent gate, never construct health UI pre-consent. |
| Reminder scheduling → OS scheduler | Must use inexact scheduling only — an exact-alarm request invites Play review friction. |
| Reminders package ↔ future flare code | The reminder must be the ONLY notification surface; flare code must never gain one. |
