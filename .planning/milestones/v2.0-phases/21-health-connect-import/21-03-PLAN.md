## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HealthReader output → EndoRepository (consent gate) | Imported rows only persist through the consent-gated repository; a pre-consent import must fail closed. |
| HC record identity → Room dedupe | metadata.id → hcRecordId (unique index) + deterministic id is the sole dedupe path; losing it double-counts days and corrupts insights. |
| changes-token cursor ↔ health DB | The cursor is device-runtime state; keeping it in DataStore (not Room) keeps it out of the synced/exported health data. |
