# Phase 19 — UI Design Contract

> Visual and interaction contract for the App Shell & Consent phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This is a PORT.** The visual/interaction direction is FIXED by the shipped iOS "Bloom" design system (`Sources/EndoApp/DesignSystem/*.swift`). This document is a *translation* of those tokens into a concrete Jetpack Compose / Material 3 contract — not a new look. Where the generic 60/30/10 or "2-weight" heuristics collide with faithful Bloom parity, **parity wins** and the deviation is noted with rationale.

### Typography (iOS `BloomTypography.swift` → Compose `TextStyle`)

Editorial headings use `FontFamily.Serif` + `SemiBold`; body/UI uses `FontFamily.Default`. Heading line-height ≈ 1.2, body line-height ≈ 1.5.

| Bloom role | Family | Size | Weight | Line height | Default color | Compose mapping |
|------------|--------|------|--------|-------------|---------------|-----------------|
| `bloomDisplay` | Serif | 30sp | `SemiBold` (600) | 36sp (~1.2) | `ink` | screen titles |
| `bloomTitle` | Serif | 28sp | `SemiBold` (600) | 34sp (~1.2) | `ink` | onboarding welcome title |
| `bloomH2` | Serif | 22sp | `SemiBold` (600) | 28sp (~1.27) | `ink` | section headings ("Ready when you are") |
| `bloomH3` | Serif | 19sp | `SemiBold` (600) | 24sp (~1.26) | `ink` | placeholder headings |
| `bloomEyebrow` | Default | 12sp | `Bold` (700) | 16sp | `inkMuted` | UPPERCASE, `letterSpacing = 1.4.sp` (iOS `kerning 1.4`), `textTransform`/`.uppercase()` at call site |
| `body` | Default | 16sp | `Normal` (400) | 24sp (1.5) | `inkSecondary` / `ink` | paragraph copy |
| `buttonLabel` | Default | 17sp | `SemiBold` (600) | 20sp | `card` (white on plum) | primary CTA label |
| `chip` / `tabLabel` | Default | 14sp | `SemiBold` (600) | 18sp | contextual | chips, tab labels |

**Weight-count deviation (documented):** the Bloom port uses **three** weights — `Normal(400)` body, `SemiBold(600)` headings/labels/buttons, `Bold(700)` eyebrow only. The generic "exactly 2 weights" heuristic is intentionally overridden to match the shipped iOS system byte-for-byte (`.bold` eyebrow is the signature tracked micro-label). Do not collapse eyebrow to SemiBold.

Map the four M3 template roles onto the Bloom scale for `Typography{}`: `displaySmall`→`bloomDisplay`, `titleLarge`→`bloomTitle`, `titleMedium`→`bloomH3`, `bodyLarge`→`body`, `labelLarge`→`buttonLabel`, `labelSmall`→`bloomEyebrow`.

## Interaction & Platform

| Concern | Contract |
|---------|----------|
| **Consent-by-construction (design invariant)** | Health/tab surfaces (`ConsentedShell`, all 3 tab composables) are referenced **only** inside `AppGate`'s `Consented ->` arm. They are not composed and not constructible in `Unknown`/`NotConsented`. Withdrawing consent flips `ConsentState` → `AppGate` recomposes → the entire shell subtree leaves composition (re-gated). Deep-link / notification intents set a non-sensitive router flag observed **only** inside the consented branch — they land on the gate, never inside it. |
| **Edge-to-edge** | `enableEdgeToEdge()` in `MainActivity.onCreate` (mandatory at targetSdk 36). `Scaffold` consumes `WindowInsets` and provides `innerPadding`; `bottomBar` handles `navigationBars` insets; onboarding scroll respects `systemBars` + `ime` union so the "I consent" button is never under the keyboard/nav bar. Placeholders pad from `Scaffold` `innerPadding`. Build this in from day one — retrofitting insets later is the expensive path. |
| **Predictive back** | On by default at targetSdk 36; do NOT intercept back generally. Recommended shell behavior: from `Insights`/`Explore`, system back returns to `Log` (via `PredictiveBackHandler` so the back-preview animates); from `Log`, back exits the app. (Exact tab-back behavior is Claude's discretion, guided by the M3 norm "back from a secondary tab returns to the start tab or exits.") Onboarding is the pre-consent root — no back handler; privacy sheet dismisses on back. |
| **Tab switch** | `onClick` sets `selectedTab`; `when(selectedTab)` renders the arm. State hoisted to `rememberSaveable` (survives config change), never a `NavHost`, never persisted to disk. Reselecting the active tab is a no-op this phase. |
| **Consent grant** | "I consent" calls `consentStore.grant()` (suspend, on a scope) — the ONLY grant site. No health composable exists before this returns `Consented`. |
| **Decline** | "Not now" is a no-op that leaves the user on the gate with nothing stored (fail-closed). It exists so declining is an explicit, visible affordance (informed-consent requirement), not a dead-end. |

## Copywriting Contract

### The substring gate (READ FIRST — non-negotiable)

Every user-facing string introduced this phase MUST be registered in `CopyAuditRegistry.sources` (via an `object …Copy : AuditableCopy`) **in the same change** that introduces the screen (`AuditableCopy.kt` harness shipped in Phase 18-05). `CopyAuditTest` runs a **case-insensitive SUBSTRING** scan against `ClaimsPolicy.causal + imperative + alarmist + forbiddenGenderedTokens + forbiddenPrecisionTokens`. Curated short copy must therefore avoid these substrings **entirely** — including innocent host words:

- `her` ⊂ **here / there / where / other / gather** → avoid all of these.
- `use` ⊂ because/used/cause → avoid.
- `start` ⊂ started/getting started → avoid.
- also avoid as substrings: `take, stop, avoid, should, must, try, cut` (imperative); `will, causes, trigger, detect, diagnose, treat, cure, prevent, because` (causal); `attack, alarm, alert, urgent, danger, predict, imminent, certain, definitely, episode, guarantee` (alarmist); `%, p =, r =` (precision).

**Long-form legal exemption (design decision for the planner):** `Disclaimer.text` legitimately contains "diagnose, treat, cure, prevent" (it states what the app does NOT do) and `PrivacyPolicyText.body` legitimately contains phrases like "Where your data lives". These two long-form constants must be handled like iOS handles them — **single-source constants with their own dedicated must-contain assertion tests** (`DisclaimerTest`: contains "not medical advice" AND "not a medical device"; `PrivacyPolicyTest`: states on-device / no servers / no accounts / no sharing / names developer + email), and **EXEMPTED from the generic forbidden-substring `CopyAudit` scan** (e.g. registered in a separate exempt list, not `CopyAuditRegistry.sources`). Do not run honest legal phrasing through the curated-copy substring gate — it would false-flag.

## Acceptance / Verification Hooks

What the phase's UI tests assert (Robolectric/JVM where the gate invariant can be proven without an emulator — preferred — else instrumented `createComposeRule`):

1. **Gate cannot be bypassed pre-consent:** with `ConsentState.NotConsented` (and `Unknown`), `onNodeWithTag("tab.log"/"tab.insights"/"tab.explore").assertDoesNotExist()` and the "I consent" button is present. No health/tab composable is in the tree.
2. **Grant reveals shell:** tapping `consent.grantButton` → state `Consented` → the three `tab.*` nodes exist; Log is the default selected tab.
