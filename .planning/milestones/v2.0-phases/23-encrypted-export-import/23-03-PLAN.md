  <behavior>
    - DocumentIo.write(uri, bytes) then DocumentIo.read(uri) returns the exact bytes (FakeDocumentIo, in-memory map).
    - SafDocumentIo.write uses openOutputStream(uri, "wt") (truncate) on Dispatchers.IO; read uses openInputStream(uri).readBytes(); a null stream throws IOException.
    - verifyWrite(io, uri, passphrase): reads back the just-written bytes, decodes them, returns true only on DecodeResult.Success; a truncating fake write (that drops the tail) makes verifyWrite return false.
    - Manifest scan: no READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE, MANAGE_EXTERNAL_STORAGE, and no INTERNET <uses-permission> element.
  </behavior>
  <action>
    Create `DocumentIo.kt`: `interface DocumentIo { suspend fun write(uri: Uri, bytes: ByteArray); suspend fun read(uri: Uri): ByteArray }`.

    Create `SafDocumentIo.kt`: `class SafDocumentIo(private val resolver: ContentResolver) : DocumentIo` — `write` = `withContext(Dispatchers.IO) { resolver.openOutputStream(uri, "wt")?.use { it.write(bytes); it.flush() } ?: throw IOException(...) }`; `read` = `withContext(Dispatchers.IO) { resolver.openInputStream(uri)?.use { it.readBytes() } ?: throw IOException(...) }`. The `"wt"` (write+TRUNCATE) mode is load-bearing (Pitfall 2 — a shorter ciphertext over a longer old file must leave no stale tail). This file MAY import android.* (it is the seam, exempt from the pure-core purity scan).

    Create `ReadBackVerify.kt`: a small pure helper `suspend fun verifyWrite(io: DocumentIo, uri: Uri, passphrase: CharArray): Boolean` that reads the URI back, runs `ExportCodec.decode`, and returns `true` only for `DecodeResult.Success`. (Uri appears here, so it is not part of the pure-core allowlist — that is fine; the decode itself stays pure.)

    Create `FakeDocumentIo.kt` (test): backs a `MutableMap<Uri, ByteArray>`; add a `truncateOnWrite: Boolean` (or a settable "drop last N bytes") knob so ReadBackVerifyTest can simulate a stale-tail/short write. Construct `Uri` via a Robolectric/`Uri.parse` (the fake test lane may use Robolectric) OR key the map on a plain wrapper if a real Uri is heavy — keep the picker/ContentResolver out.

    Create `ReadBackVerifyTest`: a healthy write→verify returns true; a truncating fake write→verify returns false (the honest "did not verify" signal that blocks a false success). Encode a small envelope via ExportCodec (23-01) to produce the bytes.

    Create `ExportManifestTest` (JUnit4, pure JVM): mirror BackupRulesTest — locate `src/main/AndroidManifest.xml` via the walk-up resolver, parse with DocumentBuilderFactory, collect every `<uses-permission>` `android:name`, and assert the set contains none of the storage permissions NOR INTERNET. Parse the XML (do NOT raw-grep the file) so an explanatory manifest comment can never false-trip the assertion (the Phase-18-06 lesson). Add a non-vacuity guard (the manifest exists and at least parses).
