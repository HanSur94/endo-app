<objective>
Build the bespoke per-data-point TalkBack semantics overlay — the HIGH-complexity, first-class accessibility deliverable (CONTEXT §Accessibility). Compose `Canvas` (including `drawText`) is completely INVISIBLE to TalkBack, and Android has NO Audio Graph / `AXChartDescriptor` equivalent, so every chart gets focusable, invisible semantics nodes — one per rendered data point — reading from the SAME gap-honest `ChartScrubSelection` resolver the visual scrub uses (Plan 02). A gap announces "not logged", a logged 0 announces a real 0; that "not logged vs 0" question is answered ONCE, in one tested place.

Purpose: this is the strongest argument for the owned-Canvas decision — a chart library would give TalkBack no honesty-aware descriptions. It mirrors the iOS non-gesture VoiceOver path and is pinned by a semantics-tree test.

Output: `ChartSemanticsOverlay` (a reusable composable that renders the transparent focusable node stack + the chart-level summary node) wired onto `TrendChart`, plus the semantics-tree test. Plans 05 (lanes) and 06 (scatter) reuse this overlay so the honesty contract extends into every chart's semantics tree without re-solving it.
</objective>

Create `com.endoapp.app.ui.charts.ChartSemanticsOverlay` — a bespoke composable (no library) that draws NOTHING visible but emits a focusable, transparent semantics node per SCRUBBABLE day, TalkBack-stepped in chronological (left→right) date order. Design it generically so lanes (Plan 05) and scatter (Plan 06) reuse it:
- Accept the chart's date domain (window-start … asOf) + the logged `List<InsightPoint>` (or an equivalent per-node model) + a `testTagRoot` + a resolver lambda defaulting to `ChartScrubSelection.resolve`.
- For each day node, resolve its text through the SAME `ChartScrubSelection.resolve(day, points)` the visual scrub uses: a LOGGED day → `contentDescription = the date (month/day)`, `stateDescription` = the `SeriesNormalization.readout`-based value ("Severity {n} of 10"); a GAP day → `contentDescription = date`, `stateDescription` = `ChartsCopy` "Not logged". The gap-vs-0 decision lives ONLY in the resolver — do not branch on value truthiness anywhere in the overlay.
- Each node is a focus target sized `≥48dp` (`Modifier.sizeIn(minHeight = 48.dp)` / `minimumInteractiveComponentSize`), positioned along the x-axis; nodes are `clearAndSetSemantics`/transparent (no visible pixels) and do not intercept the visual scrub gesture. Order the emission so TalkBack focus order is chronological.
- Emit a chart-level worded SUMMARY node (the same one-line summary shown visually above the chart) so the chart is never the sole carrier of meaning even before per-point stepping.
- testTags per UI-SPEC: per-point `${root}.point.<epochDay>` (logged) / `${root}.point.<epochDay>.notLogged` (gap); shield each node with `mergeDescendants`/`clearAndSetSemantics` so a container testTag can't mask the per-point ids.

Wire `ChartSemanticsOverlay` into `TrendChart` as an overlay child (over the Canvas), passing the trend's `testTagRoot`. Keep the visual scrub + tooltip from Plan 02 untouched; the overlay is additive.
