Rendering (mirror `InsightTrendChart.swift`, UI-SPEC §Chart Rendering 1):

- Line: `plum`, one path per `ChartSeriesGrouping.runs` (breaks at gaps, H1). Points: one dot per logged day (a logged 0 draws at the zero line, H2). Build all `Path`s inside `drawWithCache` keyed on points + size — only the scrub rule/lollipop draws per frame.
